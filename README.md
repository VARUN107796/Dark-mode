# 🌙 Dark Mode Toggle

> A responsive web application that enables users to seamlessly switch between light and dark themes, enhancing accessibility, usability, and user experience.

---

# 📖 Overview

The **Dark Mode Toggle** is a front-end web application developed to demonstrate dynamic theme switching using modern JavaScript and CSS techniques. The application allows users to toggle between light and dark modes while providing a clean, responsive, and visually appealing interface.

Developed as part of my **Full Stack Development Internship**, this project highlights practical implementation of DOM manipulation, event handling, CSS variables, and responsive web design while focusing on creating an accessible and user-friendly experience.

---

# 🎯 Project Objectives

* Build an interactive theme-switching application.
* Implement light and dark mode functionality.
* Improve user accessibility and visual comfort.
* Practice JavaScript DOM manipulation and event handling.
* Create a responsive and modern user interface.

# 🔄 Application Workflow

1. The application loads with the default theme.
2. The user clicks the theme toggle button.
3. JavaScript detects the event and updates the theme.
4. CSS variables dynamically change the appearance.
5. The interface refreshes instantly with the selected theme.
